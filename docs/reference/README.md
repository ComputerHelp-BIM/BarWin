# Reference files

Kept to check the apps against real outputs. Not used by any build.

| File | What it is | Used for |
|---|---|---|
| `dxf/standard-beam.dxf` | A standard beam detail drawing from office practice (2.6 MB, ASCII DXF). | Layers, text sizes and drawing conventions to match in the true-scale DXF (BACKLOG C1). |
| `pdf-samples/Sample_BBS_standard_form.pdf` | BBS Studio output: schedule in standard form (CADS RC layout). | Layout reference for schedules (BACKLOG C2). |
| `pdf-samples/Sample_BBS_full_data.pdf` | BBS Studio output: schedule with full data. | As above. |
| `pdf-samples/Sample_BOQ_and_cost.pdf` | BBS Studio output: BOQ, cost summary and rate analysis. | As above. |
| `pdf-samples/Sample_shop_drawings.pdf` | BBS Studio output: wall shop drawings, A3, vector. | Sheet and title-strip reference for C1. |
| `shape-figure-spec.md` | The written rules for drawing shape-code figures. | The shape-code engine and BBS Studio figures. |

The samples come from a live project and the repository is private; keep it that way, or remove these before making it public.
