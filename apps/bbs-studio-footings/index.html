BBS Studio turns footing sizes and bar arrangements into a bar bending schedule, a reinforcement detail drawing, a cutting plan and a 3D model. All dimensions are in millimetres.

In this version. Pad footings (rectangular, polygonal, circular; flat, sloped or stepped); manual entry and Excel import; IS 2502 / SP 34 and BS 8666:2020; two cutting lengths side by side; stock-length splitting with laps; a cutting plan that reuses yard offcuts; Excel, CSV, BVBS, HTML, DXF, GLB and PNG downloads.

Not yet. Columns and beams, DXF import, IFC import and export, direct PDF export, sharing a project by link.

Check before issue. The cutting plan is a best-fit heuristic, not a proven minimum. Anchorage is checked from the column face only. Verify lengths against your office practice before steel is ordered.

Changelog.

0.4.0: concrete and steel are now separate tables. Geometry holds the outline (rectangle, polygon by corner points, or circle), depth, sloped or stepped top, rotation, and per-footing overrides for covers and concrete grade. Footing cover can be one value, sides plus bottom, or sides, bottom and top. A Positions table places each footing by a named corner at its top face and sets the quantity. The Rebar table has a Shape code column (Auto, 00, 11, 21) with automatic A to C that you can override, plus calculated bar mark, cutting lengths, totals and weight. In polygon and circular footings every bar is clipped and scheduled under sub-marks (04a, 04b); Review can collapse a set to one line. The 3D view draws real shapes at their positions. Breaking: Excel files from 0.3.0 no longer import (project files still open); the old "Ends" setting became the shape code; overrides need an explicit shape code.

0.3.0: element input is now an Excel-style sheet, one block of rows per footing with a row per bar set and a blank row between footings; extra bars sit inside their footing's block. Lengths can be typed in mm, cm, m, inches or feet and fractional inches, the display unit is switchable, and a bare number is read in the display unit. Bottom X and Bottom Y bars now have separate end settings (older files apply their single setting to both). The Excel file uses the same sheet layout, with one sheet per element type; the older flat template still imports.

0.2.0: the three-pane workspace was confusing, so the app is now three full pages. Input is a grouped form per footing with a live plan sketch, and holds every input including stock and yard offcuts. Review shows checks, summary charts, 2D and 3D side by side, the schedule and the cutting plan. Outputs lists each download with what it contains, and adds a separate 3D model download. Calculations are unchanged.

0.1.0: first release, footings end to end.
