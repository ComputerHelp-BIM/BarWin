# BS 8666 shape codes

**Figure engine 1.2.0 · Reference**

Every BS 8666:2020 shape code (35) plus 51A, the hooked link used on site and under IS codes. Each is drawn as a bar of real thickness in side view and plan view (bars bent in more than one plane get one pictorial view), in four presentations: Outline, Solid, Solid + centre-line, Line with a dot at each bend.

This is the approved figure style. The same engine draws the shape figures inside BBS Studio, so a change to the figures should be made here first and carried over. The written spec is [docs/reference/shape-figure-spec.md](../../docs/reference/shape-figure-spec.md).

`index.html` is self-contained (no libraries) and opens from disk.
